# Lesson 3: Working with numbers: the area of a rectangle

Part of the **C++ for Beginners** video series.

## What you'll learn

- double for numbers with a decimal point
- Reading numbers
- Calculating and printing a result

## Programs

- `rectangle.cpp`

## Three versions

- [`starter/`](starter/): the program with a **TODO list**. Follow the TODOs while you watch the video, and write the code yourself.
- [`completed/`](completed/): the finished program, exactly as it is at the end of the video. Compare it with yours when you're done.
- [`solution/`](solution/): the answer to the **Your turn** challenge at the end of the video. Try it yourself first!

## Compile and run

From inside `starter/` or `completed/`:

```bash
g++ rectangle.cpp -o rectangle
./rectangle
```

## Your turn

Use the same width and height to calculate the perimeter too: two times (width plus height).

Try it yourself first. Then compare with the answer: [`solution/rectangle.cpp`](solution/rectangle.cpp).
