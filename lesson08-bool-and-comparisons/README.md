# Lesson 8: True or false: the bool type and comparisons

Part of the **C++ for Beginners** video series.

## What you'll learn

- The bool type: true or false
- Comparison operators == != > < >= <=
- std::boolalpha

## Programs

- `check_age.cpp`

## Three versions

- [`starter/`](starter/): the program with a **TODO list**. Follow the TODOs while you watch the video, and write the code yourself.
- [`completed/`](completed/): the finished program, exactly as it is at the end of the video. Compare it with yours when you're done.
- [`solution/`](solution/): the answer to the **Your turn** challenge at the end of the video. Try it yourself first!

## Compile and run

From inside `starter/` or `completed/`:

```bash
g++ check_age.cpp -o check_age
./check_age
```

## Your turn

Write the opposite check: is the user a minor, younger than 18? Use the less than operator, and test it with 17, 18 and 19.

Try it yourself first. Then compare with the answer: [`solution/check_age.cpp`](solution/check_age.cpp).
