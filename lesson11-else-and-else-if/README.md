# Lesson 11: Choosing between actions: else and else if

Part of the **C++ for Beginners** video series.

## What you'll learn

- if and else
- else if chains, checked from top to bottom

## Programs

- `show_access.cpp`
- `delivery.cpp`

## Three versions

- [`starter/`](starter/): the programs with a **TODO list**. Follow the TODOs while you watch the video, and write the code yourself.
- [`completed/`](completed/): the finished programs, exactly as they are at the end of the video. Compare them with yours when you're done.
- [`solution/`](solution/): the answer to the **Your turn** challenge at the end of the video. Try it yourself first!

## Compile and run

From inside `starter/` or `completed/`:

```bash
g++ show_access.cpp -o show_access
./show_access
g++ delivery.cpp -o delivery
./delivery
```

## Your turn

First, predict the prices for exactly 1 kg and exactly 5 kg. Then add a new option: over 5 and up to 10 kg costs $15. Where does the new `else if` belong?

Try it yourself first. Then compare with the answer: [`solution/delivery.cpp`](solution/delivery.cpp).
