# Lesson 7: The area of a circle: const, std::pow and std::numbers::pi

Part of the **C++ for Beginners** video series.

## What you'll learn

- const values
- Names are case sensitive
- std::pow and std::numbers::pi (C++20)

## Programs

- `circle.cpp`

## Three versions

- [`starter/`](starter/): the program with a **TODO list**. Follow the TODOs while you watch the video, and write the code yourself.
- [`completed/`](completed/): the finished program, exactly as it is at the end of the video. Compare it with yours when you're done.
- [`solution/`](solution/): the answer to the **Your turn** challenge at the end of the video. Try it yourself first!

## Compile and run

From inside `starter/` or `completed/`:

```bash
g++ -std=c++20 circle.cpp -o circle
./circle
```

## Your turn

Use the same radius to calculate the circumference too: two times pi times the radius. With a radius of 1, you should get about 6.28.

Try it yourself first. Then compare with the answer: [`solution/circle.cpp`](solution/circle.cpp).
