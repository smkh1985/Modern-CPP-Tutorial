# Lesson 13: Nested if and using-declarations: login with account status

Part of the **C++ for Beginners** video series.

## What you'll learn

- using-declarations (using std::cout;)
- The nested if: a decision inside a decision

## Programs

- `nested_login.cpp`

## Three versions

- [`starter/`](starter/): the program with a **TODO list**. Follow the TODOs while you watch the video, and write the code yourself.
- [`completed/`](completed/): the finished program, exactly as it is at the end of the video. Compare it with yours when you're done.
- [`solution/`](solution/): the answer to the **Your turn** challenge at the end of the video. Try it yourself first!

## Compile and run

From inside `starter/` or `completed/`:

```bash
g++ nested_login.cpp -o nested_login
./nested_login
```

## Your turn

Change the inactive-account message to include the username, and ask the user to contact support. Then test all three outcomes again.

Try it yourself first. Then compare with the answer: [`solution/nested_login.cpp`](solution/nested_login.cpp).
