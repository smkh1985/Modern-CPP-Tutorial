# Lesson 6: Seconds to minutes: integer division and the remainder operator

Part of the **C++ for Beginners** video series.

## What you'll learn

- Integer division on purpose
- The remainder operator %

## Programs

- `time_converter.cpp`

## Three versions

- [`starter/`](starter/): the program with a **TODO list**. Follow the TODOs while you watch the video, and write the code yourself.
- [`completed/`](completed/): the finished program, exactly as it is at the end of the video. Compare it with yours when you're done.
- [`solution/`](solution/): the answer to the **Your turn** challenge at the end of the video. Try it yourself first!

## Compile and run

From inside `starter/` or `completed/`:

```bash
g++ time_converter.cpp -o time_converter
./time_converter
```

## Your turn

Predict the output for 60 seconds and for 61 seconds, then run the program and check. Bonus: an hour has 3600 seconds. Can you convert to hours, minutes and seconds?

Try it yourself first. Then compare with the answer: [`solution/time_converter.cpp`](solution/time_converter.cpp).
