# Lesson 10: Is the number even? == and != with the remainder operator

Part of the **C++ for Beginners** video series.

## What you'll learn

- == versus =
- != (not equal)
- Checking even and odd numbers with %

## Programs

- `check_number.cpp`

## Three versions

- [`starter/`](starter/): the program with a **TODO list**. Follow the TODOs while you watch the video, and write the code yourself.
- [`completed/`](completed/): the finished program, exactly as it is at the end of the video. Compare it with yours when you're done.
- [`solution/`](solution/): the answer to the **Your turn** challenge at the end of the video. Try it yourself first!

## Compile and run

From inside `starter/` or `completed/`:

```bash
g++ check_number.cpp -o check_number
./check_number
```

## Your turn

Make one program print "even" for even numbers and "odd" for odd numbers, with two `if` statements: one with `==` and one with `!=`. Test it with 8, 7 and 0.

Try it yourself first. Then compare with the answer: [`solution/check_number.cpp`](solution/check_number.cpp).
