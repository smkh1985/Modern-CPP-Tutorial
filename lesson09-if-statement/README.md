# Lesson 9: Making decisions: the if statement

Part of the **C++ for Beginners** video series.

## What you'll learn

- The if statement
- Conditions in parentheses, blocks in braces
- Why there is no semicolon after the condition

## Programs

- `adult_check.cpp`

## Three versions

- [`starter/`](starter/): the program with a **TODO list**. Follow the TODOs while you watch the video, and write the code yourself.
- [`completed/`](completed/): the finished program, exactly as it is at the end of the video. Compare it with yours when you're done.
- [`solution/`](solution/): the answer to the **Your turn** challenge at the end of the video. Try it yourself first!

## Compile and run

From inside `starter/` or `completed/`:

```bash
g++ adult_check.cpp -o adult_check
./adult_check
```

## Your turn

Add a second `if` with the opposite condition: when age is less than 18, print "You are a minor." Test it with 20 and with 16.

Try it yourself first. Then compare with the answer: [`solution/adult_check.cpp`](solution/adult_check.cpp).
