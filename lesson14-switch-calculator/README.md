# Lesson 14: A simple calculator: char, switch and comments

Part of the **C++ for Beginners** video series.

## What you'll learn

- char for one character
- The switch statement: case, default and break
- Fallthrough
- Comments: // and /* */

## Programs

- `calculator.cpp`

## Three versions

- [`starter/`](starter/): the program with a **TODO list**. Follow the TODOs while you watch the video, and write the code yourself.
- [`completed/`](completed/): the finished program, exactly as it is at the end of the video. Compare it with yours when you're done.
- [`solution/`](solution/): the answer to the **Your turn** challenge at the end of the video. Try it yourself first!

## Compile and run

From inside `starter/` or `completed/`:

```bash
g++ calculator.cpp -o calculator
./calculator
```

## Your turn

Test the other operations yourself. Then add a new operator, the letter `a`, that calculates the average of the two numbers. Update the prompt, add a case, and don't forget its `break`!

Try it yourself first. Then compare with the answer: [`solution/calculator.cpp`](solution/calculator.cpp).
